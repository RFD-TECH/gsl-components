# MetricCard

Metric display card for dashboards and overviews. Renders a compact card with a label, large value, optional trend arrow with percentage, icon, and description.

## Loading state

Set `loading` to show shimmering skeleton placeholders instead of the label/value/trend/description content — useful while the metric value is still being fetched. The skeleton shape follows whichever of `icon`, `trend`, and `description` you pass, so the loaded and loading layouts line up.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Metric label shown above the value (uppercased via CSS) |
| `value` | `string \| number` | — | The primary metric value |
| `icon` | `ReactNode` | — | Optional icon rendered next to the label (always muted tint) |
| `description` | `string` | — | Subtitle shown below the value row |
| `trend` | `"up" \| "down" \| "neutral"` | — | Trend direction; renders an arrow icon |
| `trendValue` | `string` | — | Formatted trend text (e.g. `"+12.5%"`) |
| `variant` | `"default" \| "outline" \| "bordered" \| "soft"` | `"default"` | Card style: `"soft"` is a borderless card on a shadow with a brand watermark; `"outline"` is a bordered, no-fill card with chevron trend icons; `"bordered"` is the default layout with a 1px border added |
| `mark` | `MetricCardMark \| ReactNode \| false` | hashed from `label` | `"soft"` only: which bundled watermark to draw, your own node, or `false` for none |
| `animate` | `boolean` | `false` | Enable count-up animation from 0 to the target value on mount and value change |
| `animationDuration` | `number` | `1500` | Duration of the count-up animation in ms |
| `loading` | `boolean` | `false` | Show shimmering skeleton placeholders instead of the label/value/trend/description |
| `loadingLabel` | `string` | `"Loading metric"` | Accessible label announced while loading |
| `classNames` | `MetricCardClassNames` | — | Part-level class overrides |
| `className` | `string` | — | Merged onto the root element |

Also accepts remaining `HTMLAttributes<HTMLDivElement>`.

## Variants

Variants only affect the **trend indicator color**, not the background or text of the card:

| Variant | Trend color |
|---------|-------------|
| `"default"` | `--clet-success` (up), `--clet-error` (down), `--clet-text-muted` (neutral) |
| `"outline"` | Same as `"default"` — uses chevron icons instead of arrows, no `+`/`-` prefix |
| `"bordered"` | Same as `"default"` — adds a 1px border to the card |

### Soft variant

`variant="soft"` is the current preferred card: no border, a `--clet-shadow-md` lift, and the same
`--clet-radius-xl` corner the `Card` component uses, so a row of metrics and a card below them
share one radius. A brand watermark sits in the bottom-right, bleeding off both edges and clipped
by the card's own `overflow: hidden`.

```tsx
<MetricCard
  variant="soft"
  label="Open Risks"
  value={6}
  description="0 critical - 1 high"
/>
```

The watermark comes from a bundled set of sixteen Adinkra symbols, each id named for the symbol it
draws:

| | | | |
|---|---|---|---|
| `adinkra-hene` | `akofena` | `akoko-nan` | `akoma-ntoaso` |
| `epa` | `hwemudua` | `mate-masie` | `mpuannum` |
| `nkyimkyim` | `nkyimu` | `nyansapo` | `ohene-adwa` |
| `ohene-aniwa` | `okodee-mmowere` | `osram-ne-nsroma` | `sepow` |

Omit `mark` and one is chosen by hashing `label` (FNV-1a), so the same label always draws the same
symbol and a row of differently-labelled cards spreads across the set without anyone picking. Pass
an id to fix a specific one, a node to supply your own artwork, or `false` to draw none.

```tsx
<MetricCard variant="soft" mark="nyansapo" label="Compliance Rate" value="60%" />
<MetricCard variant="soft" mark={false} label="No watermark" value={12} />
```

Both of the mark's offsets derive from `--clet-metric-card-mark-size` at a fixed 3:1 right-to-bottom
ratio, so scaling the mark keeps the crop identical: there is one number to change, not three.

### Outline variant

Set `variant="outline"` for a bordered, no-fill card. It differs structurally from the default:

- **Page background** — uses `--clet-main-bg` (not the default variant's `--clet-default-metric-card-bg`) with a `1px` border in `--clet-border`, radius `--clet-radius-base` — reads as a bordered cutout against a panel background rather than a filled card.
- **Chevron trend icons** — `up` renders a chevron up, `down` a chevron down, `neutral` a dash.
- **No `+`/`-` prefix** — a leading sign is stripped from `trendValue` (pass `"12.5%"`, not `"+12.5%"`).
- **Larger value** — `32px` font size.
- **Padding `24px`** with a unified `8px` gap between the label, value, and description.

```tsx
<MetricCard
  variant="outline"
  label="Revenue"
  value="$128.4k"
  description="Total revenue this quarter"
  trend="up"
  trendValue="12.5%"
/>
```

## Design tokens

| Token | Default | Used for |
|-------|---------|----------|
| `--clet-metric-card-font` | `--clet-font-body` | Card font family |
| `--clet-metric-card-value-font` | `--clet-font-header` | Main value (header) font family — now defaults to the theme's header font token `--clet-font-header` |
| `--clet-metric-card-value-size` | `28px` (`32px` outline) | Main value (header) font size |
| `--clet-metric-card-value-color` | `--clet-text` | Main value (header) color |
| `--clet-metric-card-description-size` | `13px` | Description font size |
| `--clet-default-metric-card-bg` | `--clet-surface-card` | Card background — `"default"`/color variants only |
| `--clet-metric-card-mark-size` | `68px` | `"soft"` watermark size; its right/bottom bleed derive from this at 3:1 |
| `--clet-metric-card-mark-opacity` | `0.22` | `"soft"` watermark opacity |
| `--clet-metric-card-radius` | `--clet-radius-xl` | Card border-radius |
| `--clet-metric-card-shadow` | `none` | Card box-shadow |

Override card background via `--clet-default-metric-card-bg`, radius via `--clet-metric-card-radius`, or shadow via `--clet-metric-card-shadow`. The `"outline"` variant reads the global `--clet-main-bg` directly instead of `--clet-default-metric-card-bg` — override `--clet-main-bg` (or `classNames.root`) to change it.

## Notes

- Background and text remain neutral across all variants — only the trend indicator changes color. Use the `color` prop for full control.
- The icon always renders in `--clet-text-muted` regardless of variant.
- Card width is determined by the parent container. Use a grid or flex wrapper for layout.
- On mobile (`<= 768px`), padding reduces to 16px and value font size to 24px.
